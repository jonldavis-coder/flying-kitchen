Privacy

This is a draft note for a static site, not a lawyer’s policy. In demo mode, the account, comments, hearts, ratings, reports, and suggestions are stored in this browser’s local storage. The site does not send them to a server while the Supabase settings in the config are empty.

Passwords are hashed in the browser before they are stored. That only keeps them out of plain text on this device. Demo mode is for trying the kitchen, not for a private multi-user service.

The pages are static files on GitHub Pages. A future shared store would need its own note on this page before it is turned on.
